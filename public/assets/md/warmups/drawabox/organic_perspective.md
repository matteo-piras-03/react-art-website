Official website page [here](https://drawabox.com/lesson/1/organicperspective).

1) Divide the page in 3 rectangles using a ruler.
2) From now on, for each frame, draw a flowy swooping path.
3) Using the [Y Method](https://drawabox.com/lesson/1/organicperspective/ymethod), draw boxes that get smaller the further away along the given path.
4) Repeat this process until the frame is filled.

>**Mandatory for warmups**: You need to draw through the boxes, so you also need to place the back corner for each box and draw the relative edges.

## Goal

The goal of this exercise is to get used to drawing freely rotated boxes without explicit vanishing points.
