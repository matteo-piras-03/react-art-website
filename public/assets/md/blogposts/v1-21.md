Hello folks! Another update has been released with some hotfixes and new interesting features for the warmup generator.

# Changelog

Warmup generator changes:

- Added a Custom exercises main group, with a button that allows you to add a custom exercise:
    - When clicking the add button, a form will appear to input the exercise details. You must provide at least a name, and optionally an image and instructions;
    - Adding an exercise with the same name will override the existing exercise instead of creating a new one
    - Like other exercises, custom exercises can have their score edited;
    - Custom exercises can be deleted by clicking the trash icon next to them.
- Experimental: Added an import/export data feature:
    - Clicking the export button will generate a JSON file containing all your selected exercises data and custom exercises data;
    - Pasting the JSON data into the import field will allow you to restore your exercises, by clicking the import button.
- The instructions section now supports markdown formatting (cause my dumbass wanted to store text info in JSON);
- Custom exercises instructions also support markdown.

Other changes:

- Modified the background color of all sections to support different browsers and also to have a different color other than white outside the main content area;
- Self hosted the fonts cause you know about Google and their privacy policies.
