Hello folks! Another update has been released, and this time there was so much hard stuff to implement. But I really wanted to do this, so here's what I added.

# Changelog

Added the [Warmup Generator](../warmups), where users are able to randomly select warmup exercises for drawing. All data gets stored in the local browser's storage.
- The top section has two buttons: one leads to the generator page, the other to the exercise page;
- The warmup page allows the user to generate a random warmup chosen from the exercises activated in the exercise page;
- When loaded for the first time, users will have activated all of the Lesson 1 & 2 exercises, plus the Boxes and Cylinders from Drawabox, with the lowest score set;
- Lower scored exercises have a higher chance of appearing than higher scored exercises;
- The page includes a programmable timer and a skip button to change exercise. When the timer elapses the user is prompted with a score choice, which can change the exercise's score;
- The exercises page allows the user to modify the exercise pool and the score of the exercise.

Other additions:

- Cleanup of the CSS files;
- Changed the blog main font color to a higher contrast color.
