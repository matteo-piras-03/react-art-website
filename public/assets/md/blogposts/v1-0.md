# Why this website?

I have made a [carrd website](https://piras03.carrd.co) before, but I felt to add more for easening my drawing work. As such, I wanted to make a new website not only for showing off my work, but also to develop fun apps for drawing purposes. As such, I wanted to implement these functionalities next, in order from most important to least important:

- Art gallery, being able to organize drawings and studies in albums
- Warmup generator, being able to select the exercises, the frequencies of said exercises, and maybe data import/export
- Cloudflare R2 integration
- CSS cleanup for mobile usage
- Drawing heatmap, being able to track drawing hours, with possible data import/export

For now, this website is best experienced on a high resolution monitor (1080p), and not really on mobile devices. I mostly expect for this website to be used on pcs anyway.

I wanted to give a thanks to [Kavel](https://kavelbabble.com) for inspiration and help on the development of this website.
