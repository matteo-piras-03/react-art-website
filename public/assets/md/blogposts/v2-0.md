Hello folks! You may notice little to no differences between the last version, but rest assured the website has changed a lot from my end.

# Changelog

- **Ported the website to [React](https://react.dev/).** This website is now a React App and is no longer based on static HTML / CSS / JS:
    - This is a huge change for me, since I basically have wrote all of the code from scratch. To put it simply it was a much needed change given the fucking mess I made.
- The art gallery has seen some changes:
    - The carousel of each card is now gone, simply because I thought it wasn't necessary;
    - Clicking a card now changes the URL of the page (eg **art/digitalvol2** instead of **art**)
        - The modal view is shown only when the user comes from the **art** page;
        - A new Collection view is shown when the user does not come from the **art** page.
    - Modal view has a back button, useful for mobile.
- The warmup generator has slightly changed:
    - The random exercise algorithm has changed;
    - The saving format has slightly changed;
    - The "Okay" button has been removed, simply because it was pointless.
- Changed drawabox's exercises instructions to take advantage of the markdown language.
